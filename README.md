# Deco Live releases

Downloads and update information for Deco Live on macOS.

This repository contains the public update feed and release downloads. App source and signing keys are not stored here.

Download published builds from [Releases](https://github.com/Aeastr/deco-live-releases/releases). The update feed is used by Deco Live's built-in updater. No updater-enabled release has been published yet.
